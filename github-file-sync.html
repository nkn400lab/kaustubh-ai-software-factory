Send project files to your repository using your own GitHub token

1 · Connect

Use a fine-grained token restricted to this repository with Contents: Read and write. The token is held in page memory only and is not saved. This standalone page sends it to GitHub directly. Avoid public/shared computers.

2 · Files to upload

Format: JSON containing files array with path and content. You can paste Code Studio's JSON output here. No upload starts until you press the button.

Token setup guidance

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Limit access to the intended repository.
  3. Grant Repository permissions: Contents → Read and write.
  4. Create token, paste here, and never share it.
  5. Revoke token in GitHub settings when no longer needed.

This tool uploads files sequentially, checking whether a path already exists to create or update it. Each file is a separate commit. Review manifest carefully; an existing file may be overwritten.
