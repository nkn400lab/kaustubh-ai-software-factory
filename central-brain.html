Recommended execution order

  1. Describe the project in AI Project Lifecycle Orchestrator or One-Click Project Creator.
  2. Review generated files and run the Pipeline Orchestrator checks.
  3. Publish only reviewed files to GitHub.
  4. Run the Remote Test Runner / browser tests in GitHub Actions.
  5. Analyze failures, propose a patch, review it, then commit.
  6. Rerun tests and inspect artifacts before packaging or release.

Important operating limits

This Central Brain is a unified launcher and local project tracker, not a fully autonomous cloud agent. Module AI features require your own API key. GitHub publishing requires your explicit approval and token in the relevant module. Generated code is not automatically trusted, executed, deployed, or guaranteed to pass tests. GitHub Actions results must be checked on GitHub. The integrated pipeline runs static checks, browser smoke tests, and creates a source ZIP only after both test jobs pass.
