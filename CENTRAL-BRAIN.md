# Central Brain — KAUSTUBH AI Software Factory

Open `central-brain.html` as the unified module launcher and project workspace.

## Included
- Searchable launch directory for the current project modules and guides.
- Local project name, technology, repository and brief fields.
- End-to-end checklist with progress indicator.
- Browser-local save, JSON export and JSON import.
- Links to GitHub repository and Actions.

## Use order
1. Define scope and generate the project manifest.
2. Review and edit generated source.
3. Run the available manifest/static checks.
4. Publish reviewed files with explicit approval.
5. Run GitHub Actions tests and inspect logs/artifacts.
6. Analyze failures, review a repair, commit, and rerun tests.
7. Inspect package artifacts and approve release.

## Limits
This is a unified control panel, not a background autonomous agent. Checklist and project details are stored in local browser storage and do not sync across devices. Modules may require separate Gemini keys or GitHub tokens. It does not automatically run tests, execute generated code, deploy, or guarantee release readiness. Mark checklist items only after independent verification.
