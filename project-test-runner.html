Remote Test Runner

Run predefined test commands on a GitHub-hosted runner.

How it works

  1. Commit project files and tests to main.
  2. Open GitHub Actions and select Project Remote Test Runner.
  3. Click Run workflow, choose project type and start.
  4. Inspect logs and download the report artifact.
Open workflow / Run tests →

Modes

  • Static HTML: repository Python HTML validator.
  • Node.js: npm ci when lockfile exists, then npm test when a test script exists.
  • Python: install requirements when present, then unittest discovery.

No custom shell command is accepted. Node/Python tests execute project code on GitHub infrastructure only after manual workflow dispatch.

Limits

This page does not start runs or read private logs. A green run means only that selected checks passed; review coverage and logs before release.

Node needs package.json, package-lock.json and a test script. Python tests must be discoverable by unittest.
