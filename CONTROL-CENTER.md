# Factory Control Center

Open `factory-control-center.html` to launch factory modules and track a project checklist in browser-local storage.

- Module shortcuts are relative links to repository pages.
- Checklist and workspace note are stored locally in the browser; they are not synced to GitHub.
- The page intentionally does not display or claim live CI status. Use the repository Actions page for actual workflow runs.
- No tokens or API keys should be saved in the control center.
