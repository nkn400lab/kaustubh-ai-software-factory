# QA, Repair & Release Hub

Open `qa-repair-release-hub.html`. Includes a heuristic scan of pasted text, a repair checklist generator, semantic version suggestion, and release/CHANGELOG/VERSION files, with downloads and optional GitHub publishing.

It is not a test runner, does not inspect a complete repository automatically, and does not validate release readiness. The scan is heuristic only. Publishing requires a repository-scoped token; use caution and revoke after use.
